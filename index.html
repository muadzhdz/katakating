AKADEMIK & LAPORAN ID: DOC-01

Setup Margin 4-4-3-3 & Numbering di Word

Masalah: Laporan sering dicoret dosen pembimbing karena margin kiri kurang dari 4 cm atau nomor halaman cover ikut terhitung angka 1. Gunakan panduan section break dan page layout ini.

1. Layout > Margins > Custom Margins: Top: 4 cm, Left: 4 cm, Bottom: 3 cm, Right: 3 cm 2. Bab 1: Insert > Breaks > Next Page (Section Break) 3. Unlink to Previous pada header/footer Bab 1. 4. Format Page Number: Start at 1.
Tingkat: Wajib Semua Angkatan Standar Boash

GIT & DEVOPS ID: GIT-01

Menyelamatkan Repo dari Detached HEAD

Masalah: Mahasiswa melakukan checkout ke commit hash lama lalu commit di sana, menyebabkan pesan 'You are in detached HEAD state' dan commit terancam hilang saat berpindah branch.

# Simpan commit yang melayang ke branch baru: git branch temp-recovery git checkout main git merge temp-recovery # Commit Anda sekarang sudah aman kembali di main!
Kategori Emergency Git Recovery

IOT & EMBEDDED ID: IOT-02

Pinout Aman ESP32 (Hindari Boot Strapping Pin)

Masalah: ESP32 sering gagal flash atau masuk boot loop karena memasang sensor di pin GPIO 0, 2, atau 12 saat booting awal.

# Pin Aman untuk Sensor Input/Output (ESP32): GPIO 4, 18, 19, 21, 22, 23 (I2C / SPI / Digital) GPIO 34, 35, 36, 39 (Input ADC ONLY, no pullup) HINDARI GPIO 0, 2, 12, 15 untuk relay saat boot!
Hardware Safety Lab Embedded
GAME & MULTIMEDIA ID: MM-01

Blender ke Unity: Skala & Rotasi Sempurna

Masalah: Aset 3D hasil export Blender miring -90 derajat pada sumbu X saat dimasukkan ke Unity Inspector karena perbedaan sistem koordinat Z-up vs Y-up.

Di Blender sebelum Export: 1. Tekan [Ctrl + A] di Object Mode > Apply All Transforms. 2. File > Export > FBX: - [x] Selected Objects - Forward: -Z Forward | Up: Y Up - Apply Scalings: FBX Units Scale - [x] Apply Transform (PENTING!)
3D Modeling Blender 4.x & Unity
