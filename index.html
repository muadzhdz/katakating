Tentang

Apa Itu The Penguin Circle?

The Penguin Circle adalah forum belajar teknologi santai buat siapa aja yang penasaran sama terminal, CLI, Git, dan AI coding tools tapi bingung mulai dari mana.

Beda sama webinar/seminar formal — di sini nggak ada PPT 100 slide. Kita langsung buka terminal, ngetik command, dan belajar bareng. Dari 0. Santai. Setiap Jumat sore.

Dari Nol

Nggak perlu latar belakang IT. Mulai dari ls dan cd.

11 Bulan

7 bulan CLI + 4 bulan AI & project. 1 segmen = 4 pertemuan.

Gratis

Nggak ada biaya. Nggak ada iuran. Bawa laptop/HP doang.

Bisa Pake HP

Install Termux di Android — semua command dasar jalan di HP.

Belajar Bareng

Suasana santai kaya ngumpul ngulik bareng temen. Nggak ada tekanan.

Sampai Bikin Project

Phase 2 kita bikin web & mobile app beneran pake AI CLI.

Kurikulum

Apa yang Lo Pelajari?

11 bulan perjalanan dari terminal novice sampai bisa bikin project web & mobile pake AI. Nggak ada waktu terbuang.

Phase 1 — Juni s/d Desember (7 Segmen)

CLI & Command Line Fundamentals

Navigasi file, edit teks, search & grep, permission & sudo, package manager, jaringan & SSH, Git & GitHub.

Phase 2 — Januari s/d April (4 Segmen)

AI CLI + Project Simulation

Kenalan dengan AI CLI tools, project planning, web dev (Laravel/Next.js), mobile dev (Flutter) — semua pake AI.

FAQ

Pertanyaan Umum

Nggak punya laptop, bisa ikut?
Bisa. Install Termux di Android / iSH di iPhone — semua command dasar jalan. Atau dateng aja, lo bisa pairing sama peserta lain.
Nggak ngerti coding sama sekali?
Itu target utama kita. Circle ini dari 0. Pertemuan pertama aja mulai dari ls dan cd. Nggak perlu latar belakang IT.
Ada biaya pendaftaran?
GRATIS. Nggak ada biaya pendaftaran. Nggak ada iuran. Bawa laptop/HP doang.
Sampai kapan Circle ini jalan?
11 bulan — Juni 2026 sampai April 2027. Tiap segmen 1 bulan (4 pertemuan). Ada 11 segmen total.
Boleh ikut pertengahan?
Boleh. Tapi saran mulai dari awal biar nggak ketinggalan. Atau lo bisa catch up dari materi yang udah diarsipkan.
