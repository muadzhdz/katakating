// GIT

Rescue Detached HEAD

Simpan commit yang melayang ke branch baru secara aman.

git branch temp-save git checkout main git merge temp-save
// GIT

Sync & Hindari Conflict

Amankan perubahan lokal ke temporary stash sebelum pull upstream.

git stash git pull --rebase origin main git stash pop

Conventional Commits
