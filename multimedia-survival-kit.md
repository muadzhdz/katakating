## 1. Design Guidelines

### Warna

| Role | Hex | Penggunaan |
|------|-----|------------|
| Background utama | `#0a0a0a` | Dark canvas — poster bg |
| Terminal green | `#00ff41` | Judul, aksen, border |
| Terminal green soft | `#66ff66` | Hover, highlight |
| Text utama | `#e6f7ec` | Body text putih kehijauan |
| Text muted | `#889b8d` | Subtitle, caption kecil |
| Surface card | `#111511` | Kartu, panel, highlight box |
| Red (forbidden) | `#ff3355` | Hanya untuk peringatan/danger |
| Yellow (attention) | `#ffaa00` | Hanya untuk tips penting |

### Font

| Elemen | Font | Weight |
|--------|------|--------|
| Judul utama | JetBrains Mono | 700 (bold) |
| Body teks | JetBrains Mono | 400 (regular) |
| Caption kecil | JetBrains Mono | 300 (light) |
| Code / command | JetBrains Mono | 400 (regular) |

### Aset Branding di Setiap Poster

- Logo: ASCII penguin kecil di pojok kanan bawah
- Footer selalu: `The Penguin Circle — Segmen X — Bulan Tahun`
- Border: `#00ff41` 1px atau dashed

### Tone Konten

| Aspek | Gaya |
|-------|------|
| Bahasa | Indonesia (kasual, "lo/gua", kayak ngomong ke temen) |
| Nada | Santai tapi informatif, gak kaku |
| Emoji | JANGAN pake emoji — ganti dengan Boxicons (di website) |
| Command | `monospace` dengan background gelap |

## 2. Format & Spesifikasi

### Poster — IG Feed / Story

| Platform | Ukuran | Resolusi | Format |
|----------|--------|----------|--------|
| IG Feed | 1080 × 1080 px | 72 dpi | PNG |
| IG Story | 1080 × 1920 px | 72 dpi | PNG |
| WA Status | 1080 × 1920 px | 72 dpi | PNG |
| X / Twitter | 1200 × 675 px | 72 dpi | PNG |

**Rekomendasi:** Bikin 1 desain 1080×1080 (feed) + adaptasi ke 1080×1920 (story).

### Video — Reel / TikTok

| Platform | Ukuran | Durasi | Format |
|----------|--------|--------|--------|
| IG Reel | 1080 × 1920 px | 30–60 detik | MP4 H.264 |
| TikTok | 1080 × 1920 px | 30–60 detik | MP4 H.264 |
| WA Video | 1080 × 1920 px | Max 60 detik | MP4 |

**Struktur video:**

| Waktu | Konten |
|-------|--------|
| 0-3s | Hook — pertanyaan / fakta mengejutkan |
| 3-15s | Problem — "lo pasti pernah ngalamin ini" |
| 15-45s | Solusi — demo prompt AI / alur kerja |
| 45-60s | CTA — "Ikut The Penguin Circle, gratis" |

# Poster 1080x1080 dengan teks

  -font JetBrains-Mono-Bold -pointsize 36 \
  -fill '#00ff41' -annotate +60+80 "5 COMMAND WAJIB TERMINAL" \

### Command Bikin Video dari Terminal (ffmpeg)

```bash
# Rekam layar + audio
ffmpeg -f x11grab -s 1920x1080 -i :0.0 \
  -f alsa -i default \
  -t 60 \
  -c:v libx264 -crf 28 \
  -c:a aac \
  output.mp4

# Resize buat Reel (1080x1920 vertikal)
ffmpeg -i output.mp4 \
  -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2" \
  -c:a copy \
  reel.mp4
```
