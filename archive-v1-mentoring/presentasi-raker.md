### Isi

**A. Apa Itu The Penguin Circle?**

The Penguin Circle adalah forum belajar teknologi gratis untuk mahasiswa PDBI. Fokus pada:
- **CLI Linux** — navigasi, file management, system admin
- **Git & Version Control** — backup project, kolaborasi
- **Jaringan & Remote** — SSH, ping, API
- **AI Coding** — prompt engineering, AI CLI tools
- **Web Dev & Mobile Dev** — bikin website + aplikasi dari 0

Mulai dari **benar-benar 0**. Gak perlu pengalaman coding sebelumnya.

**B. Tujuan**

| Tujuan | Detail |
|--------|--------|
| Edukasi | Memberi skill praktis CLI/Git/AI yang tidak diajarkan di kelas |
| Komunitas | Membangun budaya belajar teknologi antar mahasiswa |
| Portofolio | Setiap segmen menghasilkan 1 project nyata (8 project total) |
| Inklusif | Dari 0 — tidak ada syarat, tidak ada biaya, tidak ada ikatan |

**C. Kurikulum — 8 Segmen**

| Segmen | Bulan | Topik | Output Project |
|--------|-------|-------|----------------|
| S1 | Juni | CLI Navigasi & File | Merapikan folder berantakan |
| S2 | Juli | Editor & Pengolahan Teks | Catatan kuliah + analisis teks |
| S3 | Agustus | System Admin & Tools | Toolkit admin server |
| S4 | September | Jaringan & Remote | Network diagnostic report |
| S5 | Oktober | Git & Version Control | Repository GitHub pertama |
| S6 | November | AI CLI & Prompt | Script otomatis pake AI |
| S7 | Desember | Web Dev & Deploy | Website pribadi online |
| S8 | Januari | Mobile Dev & Project | Aplikasi mobile sederhana |

**D. Metode Belajar**

Setiap pertemuan:
```
PPT 5-10 slide → Demo 1 command → Peserta praktik di WSL
```

Setiap segmen (4 minggu):
```
Minggu 1: Belajar konsep + praktik dasar
Minggu 2: Lanjutan materi + studi kasus
```

## SLIDE 9 — WARISAN DIGITAL

### Visual
- Judul: "Warisan Digital"
- Sub: "Agar ilmu tidak hilang setelah periode berakhir"
- 3 repo GitHub + 1 website

### Isi

**Masalah:**
> Setiap periode pergantian kepengurusan, ilmu dan pengalaman periode sebelumnya hilang. Angkatan baru mulai dari 0 lagi. Error yang sama terulang.

**Solusi:**
> **Warisan Digital** — sistem dokumentasi berbasis GitHub organisasi.

**4 Pilar Warisan Digital:**

| Pilar | Wadah | Isi |
|-------|-------|-----|
| Kurikulum | `github.com/penguin-circle/kurikulum` | Silabus 8 segmen, materi lengkap per pertemuan, panduan instalasi |
| Legacy | `github.com/penguin-circle/legacy` | Script yang udah dipelajari, prompt AI library, project peserta, error & tips |
| Template | `github.com/penguin-circle/template-submission` | Template folder per segmen yang bisa di-fork peserta |
