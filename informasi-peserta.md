## Cara Submit Video Tugas

Setiap **akhir segmen (minggu ke-4)** kamu wajib bikin **1 video pendek** mendemonstrasikan command yang udah dipelajari.

### Step-by-step

1. **Screen record** terminal kamu (1–2 menit aja)
   - Rekomendasi tools: OBS Studio, Kazam, atau built-in Windows Game Bar (Win+G)
   - Demo 3–5 command yang paling berkesan di segmen itu

2. **Upload ke YouTube**
   - Buka https://youtube.com
   - Klik tombol kamera (+) pojok kanan atas → **Upload Video**
   - Pilih file screen record kamu
   - **VISIBILITY**: pilih **Unlisted** (jangan Public, jangan Private)
   - Judul: `The Penguin Circle — Segmen X — [Nama Kamu]`
   - Contoh: `The Penguin Circle — Segmen 1 — Ahmad Fauzi`

3. **Copy link video**
   - Setelah upload selesai, klik **Share** → **Copy** (atau copy dari URL browser)

4. **Submit ke Google Form**
   - Buka: https://docs.google.com/forms/d/e/1FAIpQLSdYapIkh3-4iCG6mVnoLs8Gk0hZm7FvgwnqPBbPIJQPYlCFcg/viewform
   - Isi Nama, Segmen, paste link YouTube, centang konfirmasi
   - Klik Kirim

### Deadline

Video paling lambat **1 minggu setelah sesi terakhir segmen** (Minggu ke-4 + 7 hari). Form akan ditutup otomatis setelah deadline.

## Upload ke YouTube — Tips

1. **Pastikan Unlisted.** Video kamu cuma bisa dilihat sama orang yang punya link. Gak muncul di search / rekomendasi.
2. **Gak perlu edit.** Asal command jalan, suara jelas, udah cukup.
3. **Gak perlu wajah di kamera.** Screen record terminal aja.
4. **Koneksi lambat?** Upload dari kos/lab malem hari biar cepet.
5. **Gak punya channel?** Bikin pake Google Account (gratis).

## FAQ

### Video tugas dinilai?
Gak. Ini pure dokumentasi — buat portofolio kamu sendiri dan progress tracking.

### Boleh pakai musik background?
Boleh, asal suara command-nya masih kedengeran jelas.

### Screen record pake apa?
- **Windows**: Game Bar (Win+G), OBS Studio
- **Linux**: OBS Studio, Kazam, GNOME Screen Recorder (Ctrl+Alt+Shift+R)
- **Mac**: QuickTime Player → File → New Screen Recording

### Kalau lupa submit?
Gapapa — kamu tetep bisa ikut segmen selanjutnya. Tapi usahain submit buat portofolio kamu.

### Link video salah / pengen ganti?
Submit ulang aja form-nya. Nanti admin bakal pake data terbaru.
