## Konsep

The Penguin Circle adalah **simulasi pembuatan produk digital**. Bukan sekadar kelas
teori. Kamu belajar **alur** mulai dari ide, merancang (pakai AI Agent), menulis kode,
menyambungkan ke database, sampai **membuat website yang hidup di internet**.

Kita memakai 3 alat utama:

| Alat | Peran |
|------|-------|
| **AI Agent** (opencode / claude) | Menulis kode & dokumen atas perintah kamu |
| **Git / GitHub** | Menyimpan versi & berkolaborasi |
| **VS Code** | Melihat & mengelola hasil kerja |

> Setiap segmen kamu bakal membuat produk kecil yang **naik level** sampai akhirnya
> kamu dan tim membuat satu aplikasi web lengkap. Tanpa perlu hafal coding rumit —
> kamu belajar **mengarahkan AI** dan memahami alurnya.

## Persyaratan

- **WAJIB**: **VS Code** terinstall
- **WAJIB**: Akun **GitHub**

## Lingkungan Kerja

1. **Terminal (WSL Ubuntu)** → untuk menjalankan AI Agent & perintah
2. **VS Code** → untuk melihat file & hasil pekerjaan
3. **GitHub** → untuk menyimpan & berbagi project

> Alur setiap sesi: jalankan AI Agent di terminal → minta dia menulis/menghapus file →
> buka hasilnya di VS Code → commit & push ke GitHub.

## Alur per Segmen

```
Segmen 1  : Mengenal terminal & menyiapkan "dev machine"
Segmen 2  : Belajar Git & merancang produk (PRD/DESIGN)
Segmen 3  : Bikin website pertama (HTML/CSS/JS) + online di Vercel
Segmen 4  : Naik ke Next.js + API
Segmen 5  : Belajar database (Supabase) & menghubungkan data
Segmen 6  : Tambah login, upload gambar, & rapikan website
Segmen 7  : Kolaborasi tim 2 orang → rancang & bangun produk tim
Segmen 8  : Selesaikan produk tim, deploy, dan penutupan
```

## Cara Submit Tugas

Setiap **akhir segmen (modul ke-4)** kamu wajib menyelesaikan produk proyek segmen
tersebut. Cara submit-nya beda per segmen:

- **Segmen 1**: Screen record pendek terminal (1-2 menit)

## FAQ

### Saya belum bisa coding. Apakah bisa ikut?
Bisa. Fokus di sini bukan menghafal syntax, melainkan belajar **alur** dan cara
**mengarahkan AI** untuk membuat produk. Kamu belajar sambil jalan.

### Apakah saya harus hafal HTML/CSS/JavaScript?
Tidak harus hafal. Kamu belajar **membaca** struktur & mengarahkan AI. Yang penting
paham konsep: html=membuat konten, css=menata, js=membuat interaksi.

### Apakah perlu bayar untuk Vercel / Supabase / Cloudinary?
Tidak. Semua punya paket gratis yang cukup untuk project kita.

### Kenapa pakai AI Agent dan bukan ChatGPT web?
AI Agent bisa **langsung membaca & mengubah file di laptop** kamu, menjalankan perintah,
dan membuat project dari nol. ChatGPT web hanya memberi teks.

### Saya tidak suka mengetik ulang kode sendiri. Bagaimana?
Kamu memang tidak perlu mengetik ulang. AI Agent yang menulis file. Kamu melihat hasilnya
di VS Code dan mengarahkan perbaikan.

### Kalau lupa submit?
Tidak masalah — kamu tetap bisa ikut segmen selanjutnya. Tapi usahakan submit untuk
portofolio.
