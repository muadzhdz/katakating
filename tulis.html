Portal Pengajuan Jurnal & Praktikum TRM

The Penguin Circle dirancang sebagai lumbung dokumentasi perkuliahan bersama. Anda tidak perlu menguasai Git atau koding rumit untuk berkontribusi. Pilih salah satu alur pengiriman di bawah ini:

// OPSI 1: DIREKOMENDASIKAN

Formulir Web Cepat

Tulis naskah dengan bantuan editor instan & live preview di bawah. Hasil draf otomatis dikemas menjadi file Markdown dan dikirim ke WhatsApp Redaksi.

// OPSI 2: LAPORAN PRAKTIKUM

Kirim Dokumen Word (.docx)

Sudah memiliki dokumen laporan praktikum atau makalah? Kirimkan langsung filenya ke Saluran Komunitas WhatsApp agar dirapikan oleh Dewan Redaksi.

// OPSI 3: OPEN SOURCE

GitHub Pull Request

Bagi mahasiswa yang ingin membangun riwayat kontribusi open-source nyata di GitHub, Anda dapat membuat file baru di direktori articles/ lalu ajukan PR.

Formulir Pembuatan & Penyerahan Artikel
Silakan isi data naskah di bawah ini secara lengkap. Tulisan Anda akan dikurasi oleh Dewan Redaksi Divisi Kemahasiswaan HIMATRA sebelum ditayangkan di repositori web.
01 // IDENTITAS PENULIS & KONTRIBUTOR
Nama yang akan tercantum pada header artikel.
Terbuka untuk semua jurusan dan angkatan.
Digunakan pengurus untuk konfirmasi revisi atau pemberitahuan saat artikel tayang.
02 // METADATA & KLASIFIKASI ARTIKEL
Gunakan judul yang jelas, spesifik, dan memuat solusi masalah teknis.
Ditampilkan pada kartu katalog halaman utama.
03 // EDITOR NASKAH & DOKUMENTASI KODE

Belum ada naskah untuk dipratinjau. Ketik materi di tab 'Editor Tulis'.

0 kata • 0 karakter Estimasi baca: ~1 menit
04 // LANDASAN & REFERENSI ILMIAH
Wajib mencantumkan minimal 1 rujukan valid (buku, modul dosen, dokumentasi vendor, atau jurnal).
05 // PERNYATAAN KEJUJURAN AKADEMIK & ETIKA

Standar Review & Persetujuan Naskah (Editorial Board)

Setiap tulisan yang masuk akan diproses oleh 7 anggota Dewan Redaksi Divisi Kemahasiswaan melalui kriteria penilaian baku:

1. Validasi Eksekusi Nyata Seluruh sintaks perintah terminal dan kode program harus telah berhasil dijalankan tanpa galat sebelum diajukan.
2. Kejelasan Bahasa & Alur Bahasa teknis lugas, padat, dan langsung menguraikan pemecahan masalah tanpa basa-basi bertele-tele.
3. Hak Cipta & Orisinalitas Mencantumkan modul atau dokumentasi vendor asli sebagai referensi resmi di bagian penutup artikel.
4. Pengindeksan Repositori Artikel yang disetujui akan di-merge ke branch main dan langsung masuk ke katalog pencarian web.
